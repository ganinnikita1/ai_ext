# AI Bro 0.2.18 — как поставить и проверить

AI Bro — расширение с боковой панелью: **одно большое поле для вставки текста** и три кнопки
«Ответить на письмо», «Краткая сводка», «Разобрать письмо».
Расширение **не читает вкладки, письма и страницы** — вы сами вставляете текст. Письма не отправляются.

---

## 0. Что понадобится

- Chrome или Edge (Chromium). Яндекс Браузер тоже подойдёт, но проверять лучше в Chrome.
- 5 минут на демо-проверку; ключ DeepSeek — по желанию, для реальных ответов.
- Собирать ничего не нужно, расширение готово.

---

## 1. Установка (2 минуты)

**Chrome:**

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»** (Developer mode).
3. **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку:
   `C:\Users\Nikita Ganin\Documents\deepseek-harness\default-workspace\browser-ai-copilot\extension`
   (важно: папка `extension`, где лежит `manifest.json`).
5. Закрепите **AI Bro** на панели инструментов (пазл → Pin).
6. Откройте панель: иконка AI Bro или `Ctrl+Shift+Y`.

**Edge:** `edge://extensions` → «Режим разработчика» → «Загрузить распакованное» → та же папка.

**Если ставите из zip** (`extension\dist\aibro-0.2.18.zip`): распакуйте в отдельную папку так, чтобы
`manifest.json` лежал прямо в ней (например, `C:\aibro-0.2.18\manifest.json`), и выбирайте её.

> После обновления расширения: `chrome://extensions` → «Обновить» (↻) → перезагрузить вкладку почты.

## 2. Проверка без ключа (демо-режим, 3–5 минут)

Пока ключ не введён, ответы демонстрационные, но строятся из **вставленного текста**.

| # | Что сделать | Что должно получиться |
|---|---|---|
| 1 | Открыть панель AI Bro | Заголовок **AI Bro**, плашка «ДЕМО-режим · без ключа», большое поле «Вставьте текст письма или сообщения» |
| 2 | Вставить в поле любой текст письма (можно из Gmail/Яндекс Почты) | Счётчик показывает N знаков |
| 3 | Нажать **«Краткая сводка»** | 3–5 пунктов: суть/что хотят/сроки/действия — **только по вставленному тексту** |
| 4 | Нажать **«Разобрать письмо»** | Подробный разбор: суть, требования, сроки, риски, чего не хватает |
| 5 | Нажать **«Ответить на письмо»** | 3 черновика разного тона; обращение нейтральное, имя не выдумывается |
| 6 | Нажать **«Вставить в письмо»** в карточке варианта | Текст вставлен в композер открытой веб-почты; письмо **не отправлено** |
| 7 | Нажать «Очистить» | Поле очищено, чат можно начать заново |
| 8 | Вставить 13 000 знаков | Счётчик/поле обрежут до 12 000 с предупреждением |

**Важно:** AI Bro не читает сайдбары, открытые письма и страницы — даже если панель открыта на Gmail
или Яндекс Почте. Анализируется только то, что вы вставили в поле.

## 3. Проверка голоса

1. В настройках включён голосовой ввод (по умолчанию).
2. Кликните микрофон внизу панели → разрешите микрофон.
3. Скажите фразу — текст появляется в поле ввода по мере речи, автостоп по тишине.
4. Отказ в микрофоне не блокирует продукт; голос можно выключить в настройках.

Голос распознаёт облако браузера (Google в Chrome / Microsoft в Edge); расширение получает только текст.

---

## 4. Подключение DeepSeek (реальные ответы, ~2 минуты)

Модель `deepseek-flash`, reasoning **high** и адрес API зафиксированы в коде — выбирать нечего,
пользователь вставляет только ключ.

1. Создать ключ: <https://platform.deepseek.com/api_keys> (нужен аккаунт и баланс, от $1–2).
2. AI Bro → **шестерёнка** (Настройки) — или `chrome://extensions` → AI Bro → «Параметры».
3. Вставить ключ в поле **«Ключ DeepSeek»**.
4. **«Проверить соединение»** → разрешить доступ только к `api.deepseek.com` → покажет
   «Соединение работает» (без баланса и числа моделей; 401/402 — текстом).
5. **«Сохранить»**. Плашка «ДЕМО» исчезнет.
6. Вставьте текст письма → любая кнопка разбора/ответа: текст идёт потоком; reasoning high может
   думать на несколько секунд дольше.

**Стоимость:** типичный ответ ≈ **$0.0005–0.001** (off-peak). 100 писем ≈ $0.05–0.1. Peak-часы
(UTC 01:00–04:00, 06:00–10:00, пн–пт) — ×2.

## 5. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| «Manifest file is missing or unreadable» | выбрана не та папка: нужна `...\browser-ai-copilot\extension` |
| Панель не открывается | `Ctrl+Shift+Y`; закрепить иконку; `chrome://extensions/shortcuts` |
| Кнопки не срабатывают | поле пустое — вставьте текст; кнопки работают именно по нему |
| «Вставить в письмо» пишет про буфер | композер не найден (iframe/другая вёрстка) — вставьте `Ctrl+V` вручную |
| Ответ не по тому тексту | очистите поле и вставьте нужный текст заново; страница не используется |
| Ошибка 401/402 | ключ скопирован не полностью / пополнить баланс DeepSeek |
| Долго висит | reasoning high + сеть; уменьшить текст; «Проверить соединение» |
| После правок расширение старое | `chrome://extensions` → «Обновить» (↻) → перезагрузить вкладку |

Ошибки: `chrome://extensions` → AI Bro → «Ошибки»; service worker → Console; приложите скриншот панели,
версию браузера и вставленный текст (можно обезличить).

- [ ] DeepSeek flash + high: стриминг, 401/402/429, 400-fallback.
- [ ] Голос: распознавание, автостоп, отказ.
- [ ] Светлая тема, зум 125–150%, clipboard, ширина панели.
- [ ] **Никаких авточтений**: при пустом поле и открытой почте запросов `GET_MAIL`/`GET_PAGE` нет.
