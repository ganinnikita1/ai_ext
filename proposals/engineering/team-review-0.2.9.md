## Что исправлено в 0.2.10 (после ревью)

- 🔴 **B1:** кнопка панели «Отправить» → **«Спросить»**; подписи «Enter — спросить…» и «Почерк не
  отправляет письма сам — только вставка текста». Больше не читается как отправка письма.
- 🔴 **B2:** убрана вставка всех 3 вариантов на уровне сообщения; «Вставить в письмо» — только у варианта,
  вставляется один выбранный текст.
- 🔴 **B3:** демо-тексты: без e-mail в приветствии, без `[Ваше имя]`/`[уточнить срок]`, дисклеймер вынесен
  в отдельный notice и не попадает в тело/копирование.
- 🟡 **R1:** кэш активной вкладки — только активные http(s), `tabs.onRemoved`, extension/popup-вкладки
  не считаются контекстом.
- 🟡 **R3:** перед вставкой сверяются тема + отправитель/время выбранного; при пустой/degraded теме —
  особая осторожная ветка; stale-чат больше не оставляет orphan-сообщение.
- 🟡 **R5/R6:** metadata nonce-блок до 2000 символов; 400-fallback только для unknown field/thinking/
  reasoning, `invalid model` не ретраится.
- Мёртвый слайдер «Температура» убран; задачи используют проверенные значения, `executeTask` их не перезаписывает.
- `optional_host_permissions` сужены до `https://*/*` (убраны неиспользуемые localhost/127.0.0.1).
- Пересняты реальные скриншоты UI и store-кадры 1280×800 без вымышленного функционала.
- Версия **0.2.10**, zip 19 файлов (options.js включён), HTML-ссылки валидируются сборкой.

## Что осталось до беты

1. **Живой QA (обязательно):**
   - user gesture для `sidePanel.open` из контекстного меню/`Ctrl+Shift+Y`/кнопки на странице;
   - popup-fallback на Chrome 114–115 (окно с `tabId`, контекст читается);
   - Gmail, Outlook Web, Яндекс Почта, Яндекс 360: селекторы треда, picker, вставка в композер,
     SPA-переходы, вложения `.xls`, длинные треды;
   - DeepSeek с реальным ключом: `deepseek-flash`, `thinking`/`reasoning_effort`, SSE + reasoning-дельты,
     400-fallback, 402/429, стоимость;
   - голос (микрофон/`ru-RU`/автостоп/отказ), светлая тема, зум 125–150%, a11y.
2. **Продуктовые доработки (inventor):**
   - «Почему так» и «что прочитано» (truncated/degraded) в UI;
   - Style Twin: авто-сигнал при отправке/правке, а не только ручная кнопка;
   - голос «наговори ответ» → 3 варианта (сейчас уходит в чат);
   - перенести «Что учитывать» из настроек в панель; подсказка «где взять ключ»; read-only строка
     «DeepSeek flash · reasoning medium»;
   - «не учиться на моих письмах» (README обещает — в UI нет);
   - «Править / Ещё / +Тон» на карточке варианта (сейчас только копировать/вставить).
3. **Инженерные задачи (reviewer/architect):** R2 (холодный старт команды), M7 (история/квоты storage),
   M8 (автотесты в репозитории), N3 (мёртвые пресеты провайдеров/ветки), M10-остатки доков.
