# AI Bro

Браузерное расширение (Manifest V3) для Chrome и Edge. AI Bro живёт в боковой панели:
работает только с текстом, который пользователь вставил в большую ячейку: разбирает его, делает
краткую сводку и предлагает варианты ответа, подстраиваясь под ваш стиль. Понимает голосовой ввод.

> Ключевой принцип: **расширение не отправляет письма само**. Оно только предлагает текст, а вставку в
> композер и отправку делает пользователь. Вставленный текст считается недоверенным
> (защита от prompt injection).

Прежнее рабочее имя — «Почерк»; данные и настройки пользователя не меняются.

Версия: **0.2.16** (`minimum_chrome_version` 114). Обработка — DeepSeek (`deepseek-flash`), ключ добавляет пользователь.

## Что уже работает

- **Боковая панель** с историей чатов, стримингом ответа, копированием и вставкой. Кнопка отправки
  вопроса называется **«Спросить»** — она не отправляет письмо; Enter — спросить, Shift+Enter — новая строка.
- **Большая ячейка «Вставьте текст письма/переписки»** — единственный источник контекста; никакого чтения
  страниц/DOM/писем.
- **«Ответить на письмо»** — 3 варианта ответа по вставленному тексту, вставка в композер.
- **«Краткая сводка»** — 3–5 коротких пунктов по вставленному тексту.
- **«Разобрать письмо»** — подробный разбор текста; **«Разобрать всю переписку»** — весь вставленный текст
  как переписка.
- **Плавающая кнопка «AI Bro»** на страницах почты — просто открывает панель.
- **Горячая клавиша** `Ctrl+Shift+Y` (`Cmd+Shift+Y` на macOS) открывает панель.
- **DeepSeek flash** (модель зафиксирована): reasoning высокого уровня (high), стриминг, проверка соединения.
- **Вставка ответа в письмо**: content script заполняет композер; при недоступности — буфер обмена.
- **Профиль стиля**: формальность, длина, эмодзи, обращение, подпись + обучение на ваших правках
  (пары «черновик → финальный текст» хранятся локально, правила выводятся локально).
- **Голосовой ввод** через Web Speech API: кнопка микрофона, язык `ru-RU` по умолчанию, автостоп по тишине.
- **Демо-режим без ключа**: ответы генерируются локально по вставленному тексту; дисклеймер показывается
  отдельным notice в панели и не попадает в тело письма.

## Установка (unpacked)

### Chrome

1. Откройте `chrome://extensions`.
2. Включите **Developer mode** (Режим разработчика).
3. **Load unpacked** (Загрузить распакованное расширение).
4. Выберите папку `browser-ai-copilot\extension` (в ней лежит `manifest.json`).
5. Закрепите «AI Bro» на панели инструментов; сочетание клавиш меняется на `chrome://extensions/shortcuts`.

### Edge

1. Откройте `edge://extensions`.
2. Включите **Developer mode**.
3. **Load unpacked** → та же папка `extension`.
4. Панель: иконка расширения → **Открыть боковую панель** (Side panel) или `Ctrl+Shift+Y`.

Обновление после правок: кнопка «Обновить» на `chrome://extensions` / `edge://extensions`.

### Точная команда загрузки

- Chrome: `chrome://extensions` → Developer mode → Load unpacked → `<путь>\browser-ai-copilot\extension`
- Edge: `edge://extensions` → Developer mode → Load unpacked → `<путь>\browser-ai-copilot\extension`

Проверка манифеста без ручной загрузки (Windows):

```powershell
# сборка dist\aibro-0.2.16.zip + проверка ссылок манифеста
powershell -ExecutionPolicy Bypass -File .\extension\package.ps1

# Chrome/Edge: упаковка расширения (валидирует manifest и все файлы)
& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" --pack-extension="$PWD\browser-ai-copilot\extension"
```

## Настройка: API-ключ

1. Создайте ключ в кабинете DeepSeek: <https://platform.deepseek.com/api_keys>.
2. Иконка «AI Bro» → **Настройки** (или `chrome://extensions` → Details → Extension options).
3. Вставьте ключ в единственное поле → **«Проверить соединение»** → **«Сохранить»**.
4. Пока ключа нет — работает демо-режим. При первом запросе браузер спросит доступ к `api.deepseek.com`.

Провайдер, адрес и модель зафиксированы в коде: **`deepseek-flash`** на `https://api.deepseek.com`,
reasoning высокого уровня (`thinking: enabled`, `reasoning_effort: "high"`). Выбрать другую модель,
провайдера или Base URL в интерфейсе нельзя — в настройках есть только ключ, проверка соединения и
стриминг (в блоке «Дополнительно»). Температура не вынесена в UI: в режиме рассуждений DeepSeek её
игнорирует, а задачи используют собственные проверенные значения.

- **Проверить с реальным ключом:** `GET /models` (наличие `deepseek-flash`), приём `thinking` и
  `reasoning_effort`, SSE-стрим, ошибка 402 при нулевом балансе (в UI — только текст ошибки, без баланса
  и количества моделей). Если модели нет в списке — проверка соединения честно показывает ошибку; живой
  прогон генерации с ключом обязателен (в CI без ключа он недоступен).
- **Стриминг** — SSE в OpenAI-формате (`choices[0].delta.content`).

## Текст из большой ячейки — единственный источник

AI Bro **не читает страницы, DOM, письма, reading pane и сайдбары**. Вся работа идёт только с текстом,
который пользователь вставил в большую ячейку в панели.

- **Одна большая textarea** «Вставьте текст письма/переписки» — постоянный основной элемент панели,
  крупная, с прокруткой/изменением высоты, плейсхолдером и счётчиком `N / 12 000 знаков`.
- Кнопки **«Вставить из буфера»** и **«Очистить»**.
- Кнопки разбора всегда видны и работают только по тексту из ячейки:
  **«Ответить на письмо»**, **«Краткая сводка»**, **«Разобрать письмо»**, **«Разобрать всю переписку»**.
  Если поле пустое — подсказка «Вставьте текст письма/переписки в поле выше и нажмите кнопку»; запросы к
  странице/контенту не делаются.
- «Разобрать всю переписку» анализирует **весь вставленный текст как переписку** (несколько писем — ок).
- Контекст-бара «Письмо/Страница», авто-открытого письма, GET_MAIL/GET_PAGE и выбора сообщения больше нет.
- «Вставить в письмо» после ответа остаётся: текст вставляется в открытый композер через content script
  (при недоступности — копирование в буфер).
- Лимит — 12 000 знаков; при превышении текст обрезается с предупреждением.
## Как пользоваться

1. `Ctrl+Shift+Y` (или иконка) → боковая панель.
2. Вставьте скопированное письмо/кусок переписки в большую ячейку (или «Вставить из буфера»).
3. Нажмите «Ответить на письмо» / «Краткая сводка» / «Разобрать письмо» / «Разобрать всю переписку».
4. Ответ/разбор появится ниже; при необходимости нажмите **«Вставить в письмо»** — текст попадёт в открытый
   композер (или скопируется в буфер).
5. Поправьте текст и нажмите **«Учиться на правке»** — AI Bro запомнит разницу и подстроится.
6. Отправляет письмо всегда пользователь. Автоотправки нет ни в одной ветке кода.

```

  background.js          service worker: side panel, меню, команды, инжект, маршрутизация
  sidepanel.html/css/js  большая ячейка текста, история, варианты, вставка, голос, демо-режим
  content.js             только вставка в композер и плавающая кнопка (авто-чтение не используется)
  options.html/css/js    API-ключ DeepSeek, стиль, голос, приватность, проверка
  lib\
    config.js            фиксированный профиль DeepSeek (flash, reasoning high), хосты почты
    llm-client.js        fetch + SSE/NDJSON, thinking enabled + reasoning high, таймауты, ретраи
    prompts.js           русские системные промпты, обёртка недоверенных данных, варианты
    style-profile.js     локальное обучение стилю на правках
    demo.js              локальные демо-ответы без сети
  styles\base.css        токены и общие элементы UI
  icons\                 16/32/48/128 PNG
  tools\make_icons.py    генератор иконок (не входит в релиз)
  package.ps1            сборка dist\aibro-<version>.zip
```

## Приватность и безопасность

- **Что уходит в DeepSeek:** ваш вопрос, текст из большой ячейки (с лимитом) и профиль стиля. Страницы,
  DOM и письма не читаются. Запрос — на `api.deepseek.com/chat/completions`; больше ничего.
- **Где хранятся данные:** `chrome.storage.local`. Ключ и история чатов не синхронизируются.
- **Prompt injection:** вставленный текст всё равно считается недоверенным: он оборачивается в блок с
  одноразовым nonce, модели запрещено выполнять инструкции из него и что-либо отправлять.
- **XSS:** ответ модели рендерится только через DOM API (`textContent`), ссылки — с
  `rel="noopener noreferrer"`, никакого `innerHTML` из модели.
- **Нет remote code:** только локальные скрипты, без CDN. CSP: `script-src 'self'; object-src 'self'`.
- **Разрешения:** `activeTab` + `scripting` + опциональные хосты; на почту — 20 доменов декларативным
  контент-скриптом (для плавающей кнопки), `api.deepseek.com` запрашивается опционально при подключении.
- **Голос:** Web Speech API обрабатывает аудио облачным сервисом браузера (Google в Chrome,
  Microsoft в Edge). Расширение не получает и не хранит аудио; голос можно выключить в настройках.

## Известные ограничения

- **Вставка в композер хрупкая.** Gmail, Outlook Web и Яндекс Почта меняют вёрстку; используются запасные
  селекторы, при неудаче — копирование в буфер. Чтения писем/страниц нет by design.
- Содержимое внутри **iframe** (в т.ч. композер в модалке Яндекс Почты), **PDF-вьювер**, `chrome://`,
  `edge://`, Chrome Web Store не заполняются; текст копируется в буфер.
- Вставленный текст ограничен 12 000 знаков и не чанкуется в MVP.
- Имена/адресатов модель не получает из письма: только из вставленного текста; если их нет — нейтральное
  приветствие.
- Голосовой ввод зависит от браузера и сети; при недоступности Web Speech API кнопка отключается.
- Панель не умеет «закрываться» программно (нет API); `Ctrl+Shift+Y` открывает её.
- Нет OAuth, серверной части и синхронизации настроек между устройствами.
- DeepSeek без реального ключа проверен только статически (endpoint/тело/парсер); нужен прогон с ключом.

## Сборка и публикация

```powershell
powershell -ExecutionPolicy Bypass -File .\extension\package.ps1
# → extension\dist\aibro-0.2.16.zip
```

Скрипт проверяет, что все файлы из `manifest.json` на месте, складывает только runtime-файлы
(без `tools`, `dist`, README) и печатает список записей архива. Чек-лист ревью —
в `proposals\engineering\architecture.md`.
