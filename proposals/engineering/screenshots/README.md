# UI-превью «AI Bro» (для макета и скриншотов)

Это **не** скриншоты из установленного расширения, а снимки реального `sidepanel.html` / `options.html` в стиле bb (get-bb/bb)
из папки `extension/`, снятые в headless Chrome. Чтобы страница запустилась без браузерного API, в
QA-харнессе подменялся объект `chrome.*` (storage, tabs, runtime, permissions); контекст — только текст,
вставленный в большую ячейку. HTML, CSS и JS — те же самые, что в расширении; отличается только заглушка API,
поэтому вёрстку проверять по ним корректно.

| Файл | Что показывает |
| --- | --- |
| `sidepanel-demo-360.png` | боковая панель 360 px: большая textarea «Вставьте текст письма или сообщения» (110 знаков), «Вставить из буфера»/«Очистить» + счётчик, **один ряд из трёх действий** («Ответить на письмо», «Краткая сводка», «Разобрать письмо»), результат ниже; кнопок-дублей и «всей переписки» нет |
| `sidepanel-demo-500.png` | та же панель 500 px, вариант для макета |
| `options-demo-1280.png` | страница настроек: API-ключ DeepSeek, «Дополнительно» (стриминг), стиль, инструкция, голос, приватность; один набор кнопок «Проверить соединение»/«Сохранить»/«Сбросить» |
| `store/sidepanel-1280x800.png` | store-кадр 1280×800: панель 500×800 из реального sidepanel UI (демо-режим), без вымышленных функций |
| `store/options-1280x800.png` | store-кадр 1280×800 страницы настроек из реального UI, версия 0.2.17 |

Снимки сделаны 13.11.2026 при версии расширения 0.2.17 (демо-режим без ключа, контекст — текст из большой
ячейки, мок). Проверено: 320/360/500 px без горизонтального скролла, тёмная и светлая темы, контраст
текста ≥ 4,5:1 (WCAG AA), пустое поле → подсказка, busy-состояние (disabled кнопки + «Остановить»).
В реальном Chrome/Edge внешний вид совпадает, но добавляется системная рамка side panel. Для
публикации в сторах используйте `store/*-1280x800.png`; при необходимости добавьте фон/рамку макета.

Как воспроизвести: скопировать `extension/` во временную папку, заменить `<script type="module" src="sidepanel.js">`
на модуль-заглушку с моком `chrome.*`, открыть через локальный http-server и снять скриншот
`chrome --headless=new --screenshot`. Харнесс в поставку не входит. Панель уже 500 px в headless Chrome
не отрендерить напрямую (у окна минимальная ширина), поэтому кадры 360/500 снимаются через iframe
нужной ширины: так media queries и ширина считаются от точного viewport.
