# UI-превью «AI Bro» (для макета и скриншотов)

Это **не** скриншоты из установленного расширения, а снимки реального `sidepanel.html` / `options.html` в стиле bb (get-bb/bb)
из папки `extension/`, снятые в headless Chrome. Чтобы страница запустилась без браузерного API, в
QA-харнессе подменялся объект `chrome.*` (storage, tabs, runtime, permissions) и контекст письма
(Яндекс Почта). HTML, CSS и JS — те же самые, что в расширении; отличается только заглушка API,
поэтому вёрстку проверять по ним корректно.

| Файл | Что показывает |
| --- | --- |
| `sidepanel-demo-360.png` | боковая панель 360 px: демо-режим, поле «Вставьте сообщение» с текстом и чипом «Своё сообщение · 110 знаков», кнопки «Использовать»/«Вставить из буфера»/«Очистить», краткая сводка по вставленному тексту, кнопки «Ответить на письмо», «Краткая сводка», «Разобрать письмо» |
| `sidepanel-demo-500.png` | та же панель 500 px, вариант для макета |
| `options-demo-1280.png` | страница настроек: API-ключ DeepSeek, «Дополнительно» (стриминг), стиль (без выбора контекста сообщений), инструкция, голос, приватность |
| `store/sidepanel-1280x800.png` | store-кадр 1280×800 из реального sidepanel UI (демо-режим), без вымышленных функций |
| `store/options-1280x800.png` | store-кадр 1280×800 страницы настроек из реального UI |

Снимки сделаны 13.11.2026 при версии расширения 0.2.15 (демо-режим без ключа, контекст — «Своё
сообщение», мок). В реальном Chrome/Edge внешний вид совпадает, но добавляется системная рамка side panel. Для
публикации в сторах используйте `store/*-1280x800.png`; при необходимости добавьте фон/рамку макета.

Как воспроизвести: скопировать `extension/` во временную папку, заменить `<script src="sidepanel.js">`
на модуль-заглушку с моком `chrome.*`, открыть через локальный http-server и снять скриншот
`chrome --headless=new --screenshot`. Харнесс в поставку не входит.
