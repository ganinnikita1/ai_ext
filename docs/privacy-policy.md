# Политика конфиденциальности расширения «AI Bro»

**Дата вступления в силу:** 13 ноября 2026 г.
**Владелец расширения:** [ЗАМЕНИТЕ: ИП/ФИО или организация], контакт: [ЗАМЕНИТЕ: e-mail].

AI Bro — расширение для браузеров на Chromium (Chrome, Edge, Яндекс Браузер и др.) с боковой панелью:
пользователь **сам вставляет текст письма или переписки**, а расширение предлагает ответ, краткую сводку
или разбор. AI Bro **не читает открытые вкладки, письма и страницы**, не работает в фоне и **не отправляет
письма автоматически**: ответ вставляется в поле письма, отправку выполняет человек.

> Перед публикацией замените все плейсхолдеры `[ЗАМЕНИТЕ: …]` на реальные данные и опубликуйте файл по
> публичному HTTPS-URL (например, GitHub Pages), затем вставьте этот URL в политику и в кабинеты сторов.

## 1. Какие данные обрабатываются

- **Текст, который вы вставили в поле** «Вставьте текст письма/переписки» (письмо, фрагмент переписки или
  иной текст), а также ваш вопрос/команда в панели.
- **История чатов внутри расширения** (локально).
- **Профиль стиля** (формальность, длина, приветствие, подпись) и пары «черновик → ваша правка» — локально.
- **Настройки расширения** (температура/стриминг, голос, инструкция к ответам).
- **API-ключ DeepSeek**, который вы вводите сами (BYOK), и служебные статусы проверки соединения.
- **Голосовой ввод**: аудио распознаётся браузером (Web Speech API); расширение получает только текст и не
  получает и не хранит аудио.

Расширение **не собирает** содержимое открытых писем и страниц, историю браузера, cookies сайтов и данные
других вкладок. Никакого анализа DOM/страницы для ответов не выполняется — источник данных только поле ввода.

## 2. Куда передаются данные

Для генерации ответа/разбора вставленный текст, ваш вопрос, профиль стиля и инструкция отправляются
**напрямую с вашего устройства** в API DeepSeek (`https://api.deepseek.com`) — стороннему поставщику модели,
которого использует расширение. Обработка на стороне DeepSeek регулируется их условиями и политикой
конфиденциальности.

Собственного сервера у расширения **нет**: разработчик не получает и не хранит вставленный текст, историю
чатов или API-ключ. Данные не продаются, не передаются для рекламы и не используются для обучения моделей
разработчиком.

## 3. Где хранятся данные

API-ключ, настройки, история чатов и профиль стиля хранятся **локально** в хранилище браузера
(`chrome.storage.local`) в вашем профиле. Они не синхронизируются между устройствами и не выгружаются на
серверы разработчика.

## 4. Удаление данных

Вы можете в любой момент:

- очистить поле и историю чатов в панели;
- удалить ключ, настройки, историю и данные обучения — кнопкой **«Сбросить»** в настройках;
- удалить расширение — тогда все его локальные данные удаляются браузером;
- отозвать доступ к сайтам и микрофону в настройках браузера.

## 5. Разрешения и зачем они нужны

- `storage` — хранить настройки, ключ, историю и профиль стиля локально.
- `activeTab` / `scripting` — **только чтобы вставить готовый ответ в поле письма** по нажатию
  пользователя (кнопка «Вставить в письмо») и открыть панель; содержимое страницы для анализа не читается.
- `sidePanel` — показывать интерфейс ассистента в боковой панели.
- `contextMenus` — пункт меню для быстрого открытия панели.
- Домены веб-почты (Gmail, Outlook Web, Яндекс Почта/360) — чтобы показывать плавающую кнопку AI Bro и
  вставлять ответ в композер; переписка не извлекается и не анализируется.
- Опциональный доступ к сайту — только для подключения к API провайдера (DeepSeek) по вашему действию;
  можно отозвать в настройках расширения.

## 6. Безопасность

Расширение не использует удалённый код, внешние скрипты и CDN. Вставленный текст рассматривается как
недоверенные данные (защита от prompt injection): модели запрещено выполнять инструкции из текста,
автоматически отправлять письма, нажимать кнопки или переходить по ссылкам. Ответ модели рендерится как
текст без исполнения HTML.

## 7. Дети

Расширение не предназначено для детей младше 13 лет (или возраста цифрового согласия в вашей юрисдикции) и
не собирает данные о них осознанно.
