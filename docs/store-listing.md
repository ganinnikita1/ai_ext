```
AI Bro — AI-помощник в боковой панели. Вы копируете письмо или фрагмент переписки, вставляете в большое поле — и получаете ответ, краткую сводку или разбор. Расширение не читает открытые вкладки, письма и страницы и никогда не отправляет письма автоматически.

Что умеет:
• «Ответить на письмо» — три черновика разного тона по вставленному тексту; обращение нейтральное, имена не выдумываются.
• «Краткая сводка» — 3–5 пунктов: суть, что хотят, сроки, действия.
• «Разобрать письмо» — подробный разбор: требования, сроки, риски, чего не хватает.
• «Разобрать всю переписку» — весь вставленный текст как переписка (можно вставить несколько писем).
• «Вставить в письмо» — вставка готового ответа в композер Gmail/Outlook/Яндекс Почты; отправку делает человек.
• Профиль стиля: формальность, длина, приветствие, подпись, эмодзи, инструкция к ответам; обучение на ваших правках — локально.
• Голосовой ввод: наговорите текст в поле.

Приватность и безопасность:
• Модель — DeepSeek flash (BYOK): ключ хранится только в вашем браузере.
• Вставленный текст отправляется только в DeepSeek для генерации ответа/разбора; собственного сервера у расширения нет.
• Никакой телеметрии, рекламы, продажи данных.
• Нет удалённого кода и внешних скриптов; строгая CSP.
• Нет авточтения страниц/писем и автоотправки; содержимое текста считается недоверенным (защита от prompt injection).

Как начать:
1) Установите расширение, закрепите иконку AI Bro.
2) Откройте панель (иконка или Ctrl+Shift+Y), вставьте текст письма.
3) Нажмите «Ответить на письмо», «Краткая сводка», «Разобрать письмо» или «Разобрать всю переписку».
   Без ключа работает демо-режим; для реальных ответов вставьте ключ DeepSeek в Настройках.

Ограничения:
• AI Bro не читает страницы и письма сам — текст нужно вставить вручную.
• Вставка ответа в композер может быть недоступна на нестандартной вёрстке/в iframe — тогда текст копируется в буфер.
• Ответы AI могут содержать ошибки — проверяйте факты, суммы, даты и адресатов.
```

## Single purpose

```
AI Bro — помощник для ответов и разбора текста переписки, который пользователь вставляет вручную в боковой панели. Расширение не читает страницы/письма и не отправляет письма.
```

## Обоснование разрешений (permission justification)

- **storage** — «Локально хранит настройки, API-ключ (BYOK), историю чатов и профиль стиля. Данные не покидают профиль браузера.»
- **activeTab** — «Доступ к активной вкладке только по действию пользователя, чтобы вставить готовый ответ в поле письма (кнопка „Вставить в письмо“). Содержимое страницы для анализа не читается.»
- **scripting** — «Внедряет локальный content-script по действию пользователя для вставки текста в композер веб-почты и показа плавающей кнопки.»
- **sidePanel** — «Показывает интерфейс AI Bro в боковой панели браузера.»
- **contextMenus** — «Пункт меню для быстрого открытия панели AI Bro.»
- **content_scripts (20 доменов)** — «Показывает плавающую кнопку AI Bro на страницах веб-почты (Gmail, Outlook Web, Яндекс Почта/360) и помогает вставить ответ в композер. Переписка не извлекается и не анализируется.»
- **optional_host_permissions `https://*/*`** — «Запрашивается по действию пользователя для сетевого запроса к API DeepSeek по адресу провайдера; можно отозвать в настройках.»

## Data use disclosure (Chrome Web Store → Privacy practices)

- **Что обрабатывается:** текст, который пользователь вставил в поле (`Personal communications`), настройки,
  история чатов (локально), API-ключ DeepSeek (`Authentication information`).
- **Цель:** генерация ответа/сводки/разбора по вставленному тексту.
- **Передача третьим лицам:** вставленный текст и профиль стиля передаются **DeepSeek** (`api.deepseek.com`)
  для генерации; иных получателей нет.
- **Limited Use:** данные не продаются, не используются для рекламы и не читаются людьми.
- **Хранение:** локально (`chrome.storage.local`); удаляется кнопкой «Сбросить»/удалением расширения.
- **Remote code:** **No**.

## Тестовые инструкции для ревьюера (Notes / Test instructions)

```
1. Установить расширение, закрепить иконку AI Bro, открыть панель (Ctrl+Shift+Y).
2. Скопировать любой текст письма, вставить в поле «Вставьте текст письма/переписки».
3. Нажать «Краткая сводка», «Разобрать письмо», «Ответить на письмо» — работает без ключа в демо-режиме.
4. «Вставить в письмо» на странице веб-почты вставляет текст в композер; отправку делает пользователь.
5. Расширение не читает открытые страницы/письма и не отправляет письма; для живых ответов нужен свой API-ключ DeepSeek.
```
