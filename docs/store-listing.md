**Description (подробное):**

```
AI Bro — AI-помощник в браузере, который живёт в боковой панели и помогает отвечать на письма и разбирать страницы. Он читает открытое письмо или страницу, предлагает три черновика разного тона и постепенно подстраивается под ваш стиль. Письма никогда не отправляются автоматически — текст вставляете и отправляете вы сами.

Что умеет:
• Ответ на письмо в Gmail, Outlook Web, Яндекс Почте и Яндекс 360: три варианта разного тона, вставка в поле ответа.
• Разбор страницы: «объясни страницу», «что от меня хотят», «что важного в тексте», вопросы по содержимому.
• На почте: «Ответить на письмо», «Краткая сводка» (3–5 пунктов), «Разобрать письмо» (открытое), «Разобрать всю переписку»; сайдбары/списки не читаются.
• Ваш стиль: формальность, длина, обращение, подпись; обучение на ваших правках — локально.
• Голосовой ввод: наговорите ответ или вопрос.
• Вложения учитываются по именам; имена и файлы не выдумываются.
• Демо-режим без ключа: можно посмотреть, как всё работает.

Приватность и безопасность:
• Ключ DeepSeek (BYOK) хранится только в вашем браузере (chrome.storage.local).
• Содержимое писем и страниц отправляется только выбранному провайдеру (DeepSeek) для генерации ответа.
• Никакой телеметрии, рекламы, продажи данных и собственного сервера.
• Нет удалённого кода и внешних скриптов; строгая CSP.
• Расширение не отправляет письма, не нажимает кнопки и не выполняет инструкции из содержимого писем (защита от prompt injection).

Как начать:
1) Установите расширение, закрепите иконку «AI Bro».
2) Откройте письмо или страницу и нажмите иконку (или Ctrl+Shift+Y).
3) Для реальных ответов: Настройки → вставьте API-ключ DeepSeek → «Проверить соединение» → «Сохранить».
   Пока ключа нет — работает демо-режим.

Ограничения:
• Почта читается через DOM веб-версий (Gmail, Outlook, Яндекс Почта/360), поэтому после крупных обновлений вёрстки возможны деградации; есть резервные стратегии и «выделить текст вручную».
• Расширение не работает на служебных страницах браузера, в PDF-вьювере и внутри iframe.
• Ответы AI могут содержать ошибки — проверяйте факты, суммы и даты.
```

## Single purpose

```
«AI Bro» готовит черновики ответов на письма в веб-почте и разбирает открытую страницу по запросу пользователя. Отправку письма всегда выполняет человек.
```

## Обоснование разрешений (permission justification)

- **storage** — «Локально хранит настройки, API-ключ (BYOK), историю чатов и профиль стиля. Данные не покидают профиль браузера и не синхронизируются.»
- **activeTab** — «Доступ к текущей вкладке только после явного действия пользователя (клик по иконке/команда/меню) — чтобы прочитать открытую страницу и вставить текст в поле ответа.»
- **scripting** — «Внедряет локальный content-script в активную вкладку по действию пользователя для извлечения текста страницы/письма; на все сайты постоянно не внедряется.»
- **sidePanel** — «Показывает интерфейс ассистента в боковой панели браузера.»
- **contextMenus** — «Добавляет два пункта меню: „Спросить AI про выделенное“ и „AI Bro: разобрать страницу“.»
- **content_scripts (20 доменов)** — «Показывает кнопку „AI Bro“ и читает открытое письмо на страницах веб-почты: Gmail, Outlook Web (3 домена), Яндекс Почта (8 зеркал), Яндекс 360 (8 зеркал). Список ограничен доменами почты; `<all_urls>` нет.»
- **optional_host_permissions `https://*/*`** — «Запрашивается по кнопке, когда пользователь просит разобрать текущую страницу (доступ к конкретному сайту по действию). Можно отозвать в настройках; постоянного доступа ко всем сайтам нет.»

## Data use disclosure (Chrome Web Store → Privacy practices)

Отметить и указать:

- **Что собирается/обрабатывается:** `Personal communications` (содержимое писем), `Website content` (текст страницы/выделения), `Authentication information` (API-ключ DeepSeek, вводится пользователем), `User activity` (история чатов внутри расширения — локально).
- **Цель:** предоставление единственной функции — генерация черновиков ответов и разбор содержимого по запросу пользователя.
- **Передача третьим лицам:** содержимое запроса передаётся **DeepSeek** (`api.deepseek.com`) для генерации; иных получателей нет.
- **Limited Use:** подтвердить, что данные не продаются, не используются для рекламы/кредитного скоринга и не читаются людьми.
- **Хранение:** локально (`chrome.storage.local`), удаляется кнопкой «Сбросить»/удалением расширения.

## Тестовые инструкции для ревьюера (Notes / Test instructions)

```
1. Установить расширение, закрепить иконку «AI Bro».
2. Открыть любую статью, нажать иконку → «Объяснить страницу» — работает без ключа (демо-режим).
3. Открыть Gmail/Outlook/Яндекс Почту, открыть письмо → в панели нажать «Разобрать письмо» (только открытое) или «Разобрать всю переписку» → «Ответить на письмо» → «Вставить в письмо» (текст вставляется в композер, отправку делает пользователь).
4. Для живых ответов нужен собственный API-ключ DeepSeek в Настройках; для проверки функциональности достаточно демо-режима.
5. Расширение не отправляет письма само и не запрашивает доступ к сайтам в фоне.
```
